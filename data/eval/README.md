# 检索评测数据

本目录分别保存开发集与首次留出测试，两者独立统计，承担不同用途：

| 文件 | 范围 | 标注与用途 |
| --- | --- | --- |
| `retrieval-dev.json` | Transformer、BERT、LoRA，12 题、24 个证据关联 | 已观察排名后复核的开发集，用于开发诊断。 |
| `retrieval-independent-v1.json` | ResNet、U-Net、GAN，12 题、38 个证据关联 | 首次排名前冻结；参考答案人工确认，chunk 标注为 AI 辅助。 |
| `retrieval-independent-v1-results.json` | 三种方法的指标、分论文结果及逐题 Top-5 ID/分数 | 首次报告的精简发布版，不含整块原文、PDF、向量或缓存。 |

## 首次留出测试 v1

测试集固定 29 页、130 个候选分块，范围为英文、论文内检索。`provenance` 记录冻结时间、运行代码提交、原冻结文件 SHA-256，以及发布时结果已经观察的状态。发布版整理元数据、去除历史核验清单并缩短定位摘录；英文问题、相关 ID、证据页码与论文指纹均与原冻结版相同。`quote` 保存主要摘录，`additional_quotes` 保存同一分块中其余不连续摘录，均为原冻结引文中的精确子串。文件字节哈希因发布整理而不同，原冻结数据和首次结果保持不变。

每题提供中文参考答案和有限原文摘录以便核对，`human_review_status` 只表示参考答案人工确认，不意味着全部 chunk 或标注穷尽性由人工验证。正文、摘要、图注或重叠块只要直接支持至少一个实质要点即可标为相关；需额外推导、仅背景和无法独立辨认的片段不计入。`coverage_labels` 保留完整/部分覆盖信息，现有指标将它们都按二元相关计分，不据此推断完整答案。

首次结果已经观察，后续用于回归检查和误差分析，不再属于未见测试。v1 保留首次问题、金标与结果，标注更正以新版本记录并注明已观察排名。来源链接及有限摘录不代表已获得整篇论文再分发许可；本仓库不分发 PDF、完整 chunk、向量、密钥或缓存。具体数据指纹、4 处冻结前取舍及复现命令见 [首次留出测试记录](../../docs/independent-test-v1.md)。

## 开发集 v2

`retrieval-dev.json` 包含三篇本地样本论文的 12 个英文问题及 24 个问题—证据关联，覆盖数据集、训练设置、方法、指标、主结果、消融和限制。每篇 4 个问题，查询限定在指定论文内，不是多论文检索。

本开发评测集由 AI 辅助构建，并对照解析文本及相关 PDF 页面复核，尚未经过独立人工验证。评测结果用于开发诊断，不作为泛化能力的充分证据。

当前为 v2。复核结合了检索候选、语料关键词搜索和选定 PDF 页面，发生在查看 v1 排名之后，不是独立盲标，也不是独立测试集。该复核不保证标注穷尽或完全正确，仍可能存在漏标或误标。证据子串用于定位核对，不提交整篇论文 PDF 或完整 chunk。来源页面列在 JSON 中；本地 PDF 的精确版本和再分发授权未进一步核实，来源链接不代表拥有全文再分发权。

## 字段与标注口径

- `query_id`：全局唯一问题 ID；`document_id`：对应论文标识。
- `query`：英文自然语言问题，不将答案直接写入查询。
- `category`：问题所属的实验信息类别。
- `relevant_chunk_ids`：包含能支持回答的已标注证据的 chunk ID。
- `evidence`：逐个金标 ID 对应的 PDF 页码（从 1 开始）和原文短子串。
- `documents[].chunks_sha256`：当前论文有序 chunk 快照的 SHA-256 指纹，包含文本和元数据。
- 开发集 `annotation_status`：保留既有枚举 `assistant_reviewed_not_independently_validated`，表示 AI 辅助复核完成、尚无独立人工验证；首次留出测试使用单独的标注状态。

当前只纳入有已知证据的问题，不含无答案问题；后者需要另设拒答和误报指标，不能用本轮 Recall/MRR 代替。

标注并不保证穷尽所有相关片段。即使召回了未标注的有效证据，也会按未命中金标计分；因此本指标只表示对“已标注 chunk”的召回。多个 chunk 可以是同一答案的重复或相邻证据，故 Hit@K 和 Recall@K 不能混为一谈。

首轮候选复核发现 `bert-corpus` 的第 14 页 `bert_pretraining_p014_c002` 也包含语料和词数，已在 v2 加入。复核还补充了 BERT 掩码比例、LoRA 初始化和冻结参数的重复或重叠直接证据，共新增 9 个问题—证据关联。LoRA 限制问题保持原金标，后续仅解释替代方案的 chunk 不纳入。

`lora-ablation` 的问题改为询问作者描述的“总体最佳”方案，区分该结论与两个数据集各自的表格最高值；没有把答案写入查询。其余 11 个查询保持原样。v1 保存在提交 `bc806ff` 中；v2 同时改变相关集合和一个查询，两个版本的分数不能直接作为算法优劣比较。逐题依据及版本差异见评测协议。

## 固定快照

基线代码为 `7076ca7`，使用 pypdf 5.9.0，分块参数为 `max_chars=1200`、`overlap_chars=100`，三个 `document_id` 分别为 `attention_is_all_you_need`、`bert_pretraining`、`lora`。指纹计算对字典键顺序不敏感，对列表顺序、文本和元数据敏感。

指纹固定语料身份，不作为兼容不同快照的可调参数。PDF、解析器、清洗器、章节规则或分块参数变化后，证据、标注和指纹需要重新核验并记录版本。原始 PDF 不在 Git 中，新环境需自行准备相同快照；不同版本生成的 chunk 可能不能直接用于这组标注。

复现命令和当前结果见 [检索评测协议](../../docs/retrieval-evaluation.md)。
