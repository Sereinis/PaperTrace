# v0.1 PDF 解析验证记录

验证日期：2026-10-03

## 验证范围

本次验证用于确认 PaperTrace 能否对英文、可复制文本的计算机论文 PDF 进行页级解析，并生成结构稳定、页码可追踪的 JSON。

## 自动化测试

运行命令：

```powershell
python -m pytest -q
```

结果：4 项测试全部通过，覆盖：

- 页码、文本、字符数和空白状态；
- 文件不存在；
- 非法 PDF；
- UTF-8 JSON 写入和父目录创建。

## 样本解析结果

| 样本 | PDF 页数 | JSON 页数 | 页码连续 | 空白页 |
| --- | ---: | ---: | --- | ---: |
| Attention Is All You Need | 15 | 15 | 是 | 0 |
| BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding | 16 | 16 | 是 | 0 |
| LoRA: Low-Rank Adaptation of Large Language Models | 26 | 26 | 是 | 0 |

PDF 页数使用 Poppler `pdfinfo` 独立核对，与程序生成的 JSON 完全一致。

## 人工抽查

对三篇论文的首页、中间实验页和末页进行了文本抽查；另外将以下实验页渲染为图片，与提取结果进行视觉核对：

- Transformer 第 8 页：BLEU 与训练成本表格、Results 章节；
- BERT 第 7 页：SQuAD、SWAG 结果表格和 Ablation Studies；
- LoRA 第 8 页：GPT-3 适配方法对比表格和 Figure 2。

抽查结果：页码对应正确，正文和主要表格文本均被提取。复杂表格的线性文本顺序仍可能与视觉布局不同，这属于当前解析方案的已知限制。

## 当前结论

v0.1 达到以下目标：

- 能解析三篇样本论文；
- 能保存包含文件名、总页数和页级元数据的 UTF-8 JSON；
- 页码连续且与 PDF 元数据一致；
- 异常输入能返回明确错误；
- 基础测试与使用说明齐全。

下一阶段可以开始文本清洗、页级内容分块和章节识别。扫描件 OCR、复杂公式和表格结构恢复不属于 v0.1 范围。
