## 最小试验

已有检索、原文片段编号和范围复核保持不变，只针对`baselines`、`evaluation_metrics`增加可选的类型化证据条目。

- 对照方法：单模型、集成、类别未知、比较范围与来源。
- 评价指标：指标、测试范围、最终模型组成、checkpoint、解码、选参、终止条件。
- 每个条目的值必须是该条引用中的精确原文子串；程序按类型加标签投影为现有`claims`，不再由模型直接撰写字段段落。原文保留英文，不承诺全中文报告。
- 既有引用定位和第二次范围复核继续执行；被复核删除的条目仅留审计，不回灌最终结论。
- 合法引用、原文值与类型存在不证明语义正确、表格行列对应或内容完整；模型可能误贴类型或遗漏条目。类别检查只能保守降级，不能证明覆盖。

这不是PaperQA2完整的逐块摘要、评分、再综合流程。试验以单次条目抽取替代原抽取，不增加每字段最多两次生成的预算；未修改结果关系图、查询、重排或PDF解析。

`build_experiment_report(..., evidence_cards=True)`显式启用；默认`False`，网页未暴露该开关。报告v13记录开关与独立条目策略指纹，既有公开网页投影不展示私有审计。历史报告不改写。

## 引用失败定位

条目试验的引用校验现区分`reference_count_invalid`（数量/列表）、`reference_fields_invalid`（引用字段）、`reference_id_invalid`（编号类型/长度）、`reference_unknown`（编号不属于本次候选）和`reference_duplicate`（本条重复引用）。报告异常的安全`cause`可包含`validation_location`：`card_index`和可选`reference_index`均为零起始位置，仅接受0到19的整数，不包含原始编号、片段正文或原始响应。

诊断经过条目适配器、QA和报告层白名单传递，保留合法用量，不增加调用或自动修复引用。后台任务与网页仍只展示既有失败分类，不公开内部诊断细节。该能力只改善后续定位；此前原始失败响应未保存，不能追溯其具体原因。试验默认关闭、提示词、候选及质量结论不变。
